전자칠판 전용 '교실 호출' 앱 — 사용법
==================================================
ntfy 앱 대신 쓰는 우리 학교 전용 수신 앱입니다.
호출이 오면 수업 화면 위에 **전체화면 검은 배경 + 큰 글씨**로 확 뜨고, 소리가 나고,
정해둔 시간이 지나면 스스로 사라집니다. (화면을 누르면 즉시 닫힘)

만들어진 파일:  dist\교실호출.apk        ← 이것만 칠판에 설치하면 됩니다


■ 칠판에 넣는 법 (USB로 주면 됩니다)
  1) dist\교실호출.apk 를 USB에 복사
  2) USB를 전자칠판에 꽂기 → File Commander(칠판에 이미 있는 파일 앱)로 USB 열기
  3) 교실호출.apk 를 눌러 실행 → "알 수 없는 출처 허용" 물어보면 허용 → [설치]
     (F-Droid/ntfy 앱 설치할 때와 똑같은 방식입니다. Play스토어 필요 없음)
  4) 홈 화면/앱 목록에 '교실 호출' 아이콘이 생깁니다.

  ※ 인터넷으로 주고 싶으면 이 apk 파일을 카톡·메일로 보내 칠판에서 내려받아 설치해도 됩니다.
  ※ 업데이트: 새로 만든 apk를 같은 방식으로 설치하면 위에 덮어씌워집니다(설정 유지).


■ 설치 후 교실에서 할 일 (한 번만, 1분)
  앱을 열고 —
  1) '우리 반' 칸에  2-8  처럼 적기  (2학년 8반 / 208 로 적어도 알아봅니다)
  2) [① 다른 앱 위에 표시 허용]  → 목록에서 '교실 호출' 켜기 → 뒤로
       ★ 이 권한이 없으면 수업 화면 위에 못 뜹니다. 가장 중요합니다.
  3) [② 배터리 절전에서 제외]  → 허용
       (절전에 걸리면 한참 뒤에 뜨거나 연결이 끊깁니다)
  4) [저장하고 수신 시작]  → 아래 '상태'에 ● 수신 대기 중 이 뜨면 끝
  5) [테스트로 한 번 띄워보기] 눌러서 실제로 어떻게 뜨는지 확인
  · 칠판을 껐다 켜면 자동으로 다시 대기합니다(부팅 자동 실행).


■ 받는 길이 두 개입니다 (둘 다 켜두는 걸 권장)
  ① 학교망 직접  — 교사 PC(통합콘솔)가 칠판에 바로 보냄. 인터넷도, 외부 서버도 안 씀.
                   같은 학교망(같은 대역)에 있어야 하고, 콘솔에서 '칠판 앱 자동 찾기'로 한 번 등록하면 됩니다.
  ② 인터넷 중계  — ntfy.sh 를 거쳐 도착. 학교망이 서로 막혀 있어도 인터넷만 되면 옵니다.
                   채널은 '우리 반 채널(base-2-8)' 하나를 듣습니다. (전체 방송 기능은 없음)

  콘솔에서는 [교실 호출] 탭 → '교실 설치 도우미…' 에서
     · 보내는 방법: 학교망 직접 먼저 → 안 되면 중계(권장) / 중계만 / 직접만
     · [칠판 앱 자동 찾기] : 학교망을 훑어 '몇 학년 몇 반 칠판이 어느 주소인지' 자동 등록
     · [직접 전송 테스트]  : 고른 반 칠판에 바로 한 번 보내보기
  를 할 수 있습니다.
  ※ 같은 호출을 두 길로 동시에 보내지는 않습니다(직접이 성공하면 중계는 안 씀 → 두 번 안 뜸).


■ 앱 설정 항목
  · 우리 반            : 이 칠판이 받을 반 (필수)
  · 교실 이름          : 콘솔 목록에 보일 이름 (선택)
  · 중계 채널 이름(base): 콘솔 설정의 classroom_call.topic 과 같아야 함
  · 직접 수신 포트     : 기본 8787 (콘솔의 lan_port 와 같아야 함)
  · 직접 수신 암호     : 비워두면 검사 안 함. 넣으면 콘솔 lan_key 에 같은 값
  · 화면에 띄워 둘 시간(초) : 기본 60초
  · 호출음 / 음성으로 읽어주기 : 음성은 칠판에 한국어 TTS가 있을 때만 동작


■ 잘 안 될 때
  · 호출이 아예 안 뜬다     → 앱 화면 '상태'에 ⚠ 권한 경고가 있는지 확인(①번 권한)
  · 앱 안엔 기록이 남는데 화면에 안 뜬다 → ① 권한 문제일 가능성이 큽니다
  · 중계는 되는데 직접이 안 된다 → 교사 PC와 칠판이 다른 망일 수 있음. 그래도 중계로 도착하므로 그대로 써도 됩니다.
  · 한참 뒤에 뜬다          → ② 배터리 절전 제외를 확인
  · 칠판이 HDMI(PC 화면)를 비추는 중이면 안드로이드 화면이 안 보이므로 못 봅니다
    → 그 상황은 교실 PC의 '교실수신기'가 대신 커버합니다(두 개 같이 쓰면 빈틈이 메워짐).
  · 칠판이 완전히 꺼져 있으면 방법이 없습니다.


■ 앱을 고치고 다시 만들 때 (개발용)
  · 소스: app\src\kr\okjung\classcall\*.java , app\AndroidManifest.xml
  · 빌드: 빌드.bat  (필요한 것: JDK 17 + C:\android-sdk 의 build-tools/platforms)
  · 결과: dist\교실호출.apk
  · 서명키: keys\classcall.jks (비번 classcall) — ★ 이 파일을 잃어버리면 '업데이트 설치'가 안 되고
    칠판마다 기존 앱을 지우고 새로 깔아야 하니 백업해 두세요.
