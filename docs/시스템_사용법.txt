교실 호출 시스템 — 사용법
==================================================
교무실 자리에서 한 줄 보내면, 그 반 교실 화면에만 크게 뜹니다.
(예: "지수야~ 6층 생활교육부로 오세요")  평소엔 까만 화면, 올 때만 큼지막하게.

폴더 안 파일
  · 표시기.html   ← 교실 스마트폰/전자칠판에서 여는 화면 (까만 화면 → 메시지 표시)
  · 전송기.html   ← 선생님이 메시지 보내는 화면 (폰/PC 아무거나)
  · 교실수신기.py ← 교실 윈도우 PC 상주형 수신기 (평소엔 화면 안 차지)


■ ★ 반별 채널 (중요) ★
  채널(토픽) 이름을 반마다 다르게 해서, 원하는 반에만 보냅니다.

    기본 이름(base)      :  myschool-call-CHANGEME            ← 모든 교실 공통(여기로 직접 보내진 않음)
    반별 채널            :  myschool-call-CHANGEME-<학년>-<반>
                            예) 2학년 8반 → myschool-call-CHANGEME-2-8

  · 보내는 쪽(통합콘솔 / 전송기.html): 받는 반 버튼을 고르면 그 반 채널로만 보냅니다.
    (여러 반 동시 선택 가능. 전체 방송 기능은 없음 — 필요한 반을 각각 누르면 됨)
  · 받는 쪽(교실 장비): '우리 반 채널' 하나만 듣습니다. → 옆 반 호출은 안 뜹니다.

  ※ 통합콘솔의 [교실 호출] 탭 → '교실 설치 도우미…' 버튼을 누르면
    반마다 넣어야 할 주소·채널·'반.txt' 값이 표로 나오고, 복사/저장할 수 있습니다.


■ 통신 원리 (간단히)
  인터넷의 무료 알림중계 ntfy.sh 를 씁니다. 서버 운영·가입 필요 없음.
  전송기에서 보내면 → ntfy.sh 가 → 그 채널을 듣고 있는 교실로 즉시 밀어줍니다.
  둘 다 '인터넷만' 되면 층/건물 상관없이 도착합니다. (와이파이든 데이터든)


■ [권장] 교실 컴퓨터(전자칠판 연결 윈도우 PC)에 상주 수신기 설치  — 화면을 평소엔 안 차지함
  전자칠판은 수업에 써야 하니 크롬 표시기를 계속 띄워둘 수 없죠.
  대신 '교실수신기'를 백그라운드에 상주시키면, 평소엔 화면을 전혀 안 쓰다가
  호출이 올 때만 전체화면으로 확 떴다가 몇 초 뒤 사라져 원래 수업화면으로 돌아갑니다.

  준비(한 번만):
  1) 파이썬 되는 PC에서 '교실수신기_빌드.bat' 실행 → dist\교실수신기.exe 생성
       (교실 PC에 파이썬이 있으면 exe 없이 '교실수신기_실행.bat' 로 바로 실행해도 됨)
  2) 교실수신기.exe 를 USB로 교실 컴퓨터에 복사.
  3) ★ 그 교실이 몇 학년 몇 반인지 알려주기 ★
       exe 와 같은 폴더에 메모장으로 '반.txt' 를 만들고 한 줄만 적기.
           2-8        (또는  2학년 8반  /  208  로 적어도 알아봄)
       → 이제 그 PC는  base-2-8(우리 반) 채널을 듣습니다.
       · '반.txt' 가 없으면 아무 호출도 받지 않습니다(시작 알림에 경고가 뜸).
       · base 채널 자체를 바꾸려면 '토픽.txt' 에 새 base 를 적으면 됩니다.
  4) 자동 대기시키기: 교실수신기.exe 바로가기를 '시작프로그램'에 넣기.
       (윈도우+R → shell:startup → 그 폴더에 exe 바로가기 붙여넣기)
       → 컴퓨터 켤 때마다 자동 수신 대기(우측 상단에 '수신 대기 시작 ✓ [2학년 8반]' 잠깐 뜸).
  · 끄기: '교실수신기_종료.bat' 실행(또는 작업관리자).
  · 호출 오면: 소리+전체화면 큰 글씨, 왼쪽 위에 '2학년 8반' 이라고 작게 표시
    → 60초 뒤 자동 사라짐(화면 아무 데나 클릭/Esc로 즉시 닫기).

  ※ 주의: 다른 선생님이 '본인 노트북을 HDMI로 꽂아' 수업하면, 그 순간 칠판은
    노트북 화면만 비추므로 교실 PC에서 뜬 호출은 안 보입니다(입력이 노트북이라서).
    교실 PC(윈도우)로 수업할 때 확실히 뜹니다.


■ [추천] 전자칠판 전용 앱 '교실 호출'  — ntfy 앱 대신 (2026-09-17 신설)
  우리가 직접 만든 안드로이드 앱입니다. 폴더: Desktop\개발\교실호출앱  (결과물 dist\교실호출.apk)
  · ntfy 앱은 '알림'이라 화면 위에 작게 뜨거나 안 뜰 때가 있는데, 이 앱은 수업 화면 위에
    전체화면 검은 배경 + 큰 글씨로 확 띄우고 소리를 냅니다. 정해둔 시간 뒤 자동으로 사라짐.
  · 받는 길 2개를 동시에: ① 학교망에서 교사 PC가 바로 보내기(인터넷·외부서버 불필요)
                          ② 인터넷 중계(ntfy) — 우리 반 채널
  · 설치: apk를 USB로 칠판에 복사 → File Commander로 실행 → 허용 → 설치 → 앱에서 '우리 반'만 적고
          권한 2개(다른 앱 위에 표시 / 절전 제외) 허용 → [저장하고 수신 시작]. 칠판 재부팅해도 자동 대기.
  · 자세한 건 Desktop\개발\교실호출앱\사용법.txt 참고.


■ [보완] 전자칠판 자체(내장 안드로이드)에 ntfy 앱  — 전용 앱 대신 쓸 때
  ▶ 한 번 보내면 위 윈도우 수신기와 이 칠판 앱이 '동시에' 받습니다(같은 채널). 두 번 보낼 필요 없음.
  ▶ 이 앱은 PC를 안 거치고 칠판이 직접 받으므로, 칠판만 켜져 '안드로이드 화면' 상태면 PC가 꺼져 있어도 뜸.

  ※ 우리 칠판(컴버스 안드로이드)엔 Play스토어가 없음 = 구글서비스 없음.
    → 구글 의존이 없는 'ntfy F-Droid 버전'을 써야 함(앱이 스스로 상시연결 유지해 받음).

  세팅(한 번만):
  1) 칠판 Chromium 열기 → 주소창:  f-droid.org/en/packages/io.heckel.ntfy/
  2) 그 페이지에서 'Download APK' → apk 내려받기.
  3) 다운로드 알림 누르거나 File Commander로 그 apk 열기 → '알 수 없는 출처 허용' 뜨면 허용 → 설치.
  4) ntfy 앱 → + (구독 추가) → 그 교실의 채널을 구독:
       · 자기 반 채널:  myschool-call-CHANGEME-<학년>-<반>   (예: 2학년8반 → myschool-call-CHANGEME-2-8)
       서버는 기본(ntfy.sh).
  5) 각 구독 눌러 → 우선순위 'Max' + 소리 켜기, 칠판 볼륨 올려두기.
     (콘솔이 이미 Priority:urgent 로 보내므로 긴급/소리로 크게 뜸)
  · 설치가 막혀 있으면(학교 정책) 만든이에게 문의 — 다른 사이드로드 방법 안내.

  한계(정직하게):
   · 칠판이 완전히 꺼져 있으면 못 뜸(전원 나간 화면은 소프트웨어가 못 켬).
   · 칠판이 'HDMI(PC 화면)'를 비추는 중이면 안드로이드 알림이 뒤로 가려 안 보일 수 있음
     → 그 상황은 위 '윈도우 수신기'가 대신 커버.  두 개를 같이 쓰면 서로 빈틈을 메움.


■ (대안) 교실 스마트폰 세팅 (표시기)  — 한 번만
  1) 표시기.html 을 그 폰으로 옮겨서 크롬으로 엽니다.
       ★ 주소 뒤에 그 반을 꼭 붙이세요:   표시기.html?c=2-8    (2학년 8반)
         → base-2-8(우리 반) 채널을 받습니다.
         (?c= 를 안 붙이면 아무 호출도 받지 않습니다 — 시작 화면에 경고가 뜸)
       · 옮기는 가장 쉬운 법: 카카오톡 '나에게 보내기'로 표시기.html 전송 →
         폰에서 파일 탭 → '크롬으로 열기'   (단, 이 방식은 ?c= 를 붙이기 어려우니
         아래 [항상 되는 방법]의 인터넷 주소 방식이 반별 설치엔 훨씬 편합니다)
  2) 화면을 한 번 터치 → 전체화면 + 소리 + 화면꺼짐방지가 켜집니다.
       (시작 화면에 '📺 2학년 8반' 과 받는 채널이 표시됩니다 — 반이 맞는지 확인)
  3) 오른쪽 위 점이 초록색이면 연결됨. (빨강=인터넷 확인 또는 ?c= 누락)
  4) 폰을 교실 앞에 세워두고 충전기를 꽂아 두세요.
  ※ 팁: 폰 설정에서 '화면 자동 꺼짐/자동 회전'을 꺼두면 더 안정적입니다.


■ 선생님(보내는 쪽) 세팅 (전송기)
  · 전송기.html 을 본인 폰이나 교무실 PC 크롬에서 열고 즐겨찾기(홈 화면 추가).
  · 받는 학생 이름 적고, '보내는 사람'(예: 권혁규T) 적고,
    ★ 받는 반을 고르고(여러 반 동시 선택 가능) ★
    장소 버튼 누르고(또는 직접 입력) → [보내기] → 그 반 교실 화면에만 뜸.
    (보내는 사람과 마지막에 고른 반은 다음에 자동으로 채워집니다)
  · 교실 화면엔  "지수야~ 6층 생활교육부로 오세요"  아래에  "— 권혁규T 로부터"  가 작게 뜸.
  · "✓ 2학년 8반 에 보냈습니다" 뜨면 성공.
  · 학년별 반 수가 다르면 주소 뒤에:  ?g=1:6,2:8,3:6   (1학년 6반, 2학년 8반, 3학년 6반까지)
  · 통합콘솔(학교업무콘솔)의 [교실 호출] 탭도 똑같은 규칙으로 보냅니다.


■ [항상 되는 방법] 교실 폰에서 파일이 안 열리거나 연결이 안 될 때
  로컬 파일 대신 '인터넷 주소(URL)'로 열면 가장 확실합니다. 무료로 올리는 법:
  1) github.com 가입(무료) → 새 저장소(New repository) 만들기(Public)
  2) 표시기.html · 전송기.html 을 업로드(Add file → Upload files → Commit)
  3) 저장소 Settings → Pages → Branch를 main / (root) 로 저장
  4) 잠시 뒤 https://<아이디>.github.io/<저장소>/표시기.html 주소가 생김
  5) 그 주소를 통합콘솔의 '교실 설치 도우미'에 넣으면 반별 주소를 자동으로 만들어 줌
       예) https://<아이디>.github.io/<저장소>/표시기.html?c=2-8
  6) 교실 폰 크롬에서 그 반 주소 열기 → '홈 화면에 추가' → 아이콘으로 실행
  ※ 주소 뒤 옵션:  ?c=2-8   (그 반 채널 받기 — 반별 설치의 핵심)
                   ?sec=60  (60초 뒤 자동으로 사라짐, 기본 60초)
                   ?t=다른base (base 채널을 통째로 바꾸고 싶을 때)


■ 개인정보/보안 참고
  · 채널(myschool-call-CHANGEME…)은 '채널 이름'입니다. 이 이름을 아는 사람은
    누구나 보내거나 볼 수 있어요(무작위라 사실상 남이 알 수 없지만, 암호화는 아님).
  · 반별 채널은 base 뒤에 -학년-반 을 붙인 것이라, base 를 아는 사람은 반별 채널도 유추 가능합니다.
    (교내용 호출 수준에는 충분하지만, 민감한 내용은 보내지 마세요)
  · base 를 바꾸고 싶으면 보내는 쪽·받는 쪽 모두 같은 값으로 바꿔야 합니다
    (콘솔 설정 classroom_call.topic / 표시기·전송기의 ?t= / 수신기의 토픽.txt).


■ 잘 안 될 때
  · 표시기 점이 빨강 → 그 폰 인터넷 확인. 초록 되면 정상.
  · 보내도 안 뜸 → ★ 반이 맞는지부터 확인 ★
      보내는 쪽에서 고른 반 = 받는 쪽의 ?c= / 반.txt / ntfy 구독 채널 이 같아야 합니다.
      (예: 2학년 8반 → 양쪽 다  ...-2-8)
  · 콘솔 보낸 내역에 '송신 실패'가 뜨는데 칠판엔 떴다면 → 앱의 base 칸에 반이 붙어 있는지 확인(v1.2+는 자동 교정).
  · 학교 와이파이가 ntfy.sh를 막으면 폰 데이터(LTE/5G)로 해보세요.
  · 소리가 안 남 → 교실 폰에서 '화면 터치로 시작'을 꼭 한 번 해야 소리가 켜집니다.
