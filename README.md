# 교실 호출 (Classroom Call)

교무실에서 한 줄 보내면 **그 반 전자칠판에만** 수업 화면 위로 크게 뜨는 호출 시스템입니다.
평소엔 화면을 전혀 차지하지 않다가, 호출이 올 때만 검은 전체화면 + 큰 글씨로 떴다가 스스로 사라집니다.

> "지수야~ 6층 생활교육부로 오세요" — 교무실에서 보내면 2학년 8반 칠판에만 뜹니다.

서울의 한 중학교에서 실제로 쓰고 있는 도구입니다. 교내방송으로 전교생을 방해하지 않고 한 반만 부를 수 있고,
교실에서 **답장 버튼**을 누르면 교무실 화면에 바로 표시됩니다.

## 무엇이 들어 있나

| 폴더 | 내용 |
|---|---|
| `android/` | 전자칠판용 안드로이드 앱 (자바, 외부 라이브러리 0개, APK 약 32KB) |
| `web/` | `표시기.html` (교실 스마트폰용 수신 화면), `전송기.html` (교사용 발송 화면) |
| `classroom-pc/` | 교실 윈도우 PC 상주형 수신기 (파이썬 Tkinter) |
| `docs/` | 설치·운영 사용법 (교실에서 그대로 따라 할 수 있게 쓴 문서) |
| `PROTOCOL.md` | 채널 규칙·수신확인·답장 규약 (직접 구현하려면 이것만 보면 됩니다) |

## 특징

- **반별 채널** — 채널 이름을 `base-학년-반` 으로 나눠, 고른 반에만 전달됩니다. 옆 반에는 안 뜹니다.
- **받는 길 두 개** — 같은 학교망이면 교사 PC가 칠판으로 **직접**(외부 서버·인터넷 불필요), 막혀 있으면 **인터넷 중계(ntfy.sh)** 로 자동 전환합니다. 같은 호출을 두 길로 동시에 보내지 않아 두 번 뜨지 않습니다.
- **수신 확인 / 송신 실패** — 칠판이 화면에 띄운 순간 자동으로 확인 신호를 돌려보냅니다. 정해진 시간 안에 확인이 없으면 보낸 쪽에 **"송신 실패 — 칠판이 꺼져 있거나 앱이 꺼짐"** 이라고 표시됩니다. 늦게 켜져서 받으면 "늦게 수신 확인"으로 갱신됩니다.
- **답장 버튼** — 교실에서 "네, 바로 보낼게요 / 수업 끝나고 보낼게요 / 학생이 지금 없어요 / 확인했습니다" 중 하나를 누르면 교무실 화면에 뜹니다. 문구는 바꿀 수 있습니다.
- **권한이 없는 칠판도 대응** — 전자칠판 펌웨어에 '다른 앱 위에 표시' 설정 화면이 아예 없는 기종이 있습니다. 그런 기기에서는 전체화면 알림(full-screen intent) 경로로 대신 띄웁니다.
- **서버가 필요 없습니다** — 계정 가입도, 서버 운영도 없습니다. 중계는 무료 공개 서비스 [ntfy.sh](https://ntfy.sh) 를 그대로 씁니다.
- 부팅하면 자동으로 수신 대기, 화면이 꺼져 있으면 깨워서 표시합니다.

## 빠르게 써보기

1. **채널 이름 정하기** — 코드의 `myschool-call-CHANGEME` 를 **아무도 못 맞출 임의의 문자열**로 바꾸세요
   (예: `우리학교약칭-call-3f7a91c2` 처럼 학교 약칭 + 무작위 8자리). 보내는 쪽과 받는 쪽이 같아야 합니다.
   > ⚠️ 채널 이름은 사실상 비밀번호입니다. 이름을 아는 사람은 누구나 보내고 볼 수 있으니 공개하지 마세요.
2. **교실 스마트폰으로 먼저 확인** — `web/표시기.html` 를 웹에 올리고 `?c=2-8` 을 붙여 열면 2학년 8반 수신 화면이 됩니다.
   `web/전송기.html` 을 열어 반을 고르고 보내면 바로 뜹니다. (서버 없이 정적 파일 두 개면 끝)
3. **전자칠판 앱** — `android/빌드.bat` 로 APK를 만들고(JDK 17 + Android SDK 필요), USB로 칠판에 옮겨 설치합니다.
   앱에서 '우리 반'만 적고 [저장하고 수신 시작]을 누르면 끝입니다.
4. 자세한 내용은 [`docs/시스템_사용법.txt`](docs/시스템_사용법.txt), [`docs/앱_사용법.txt`](docs/앱_사용법.txt) 를 보세요.

## 안드로이드 앱 빌드

Android Studio·Gradle 없이 SDK 도구만 직접 호출합니다. 의존성이 0개라 빌드가 몇 초면 끝납니다.

```
aapt2 compile/link → javac → d8 → classes.dex 넣기 → zipalign → apksigner
```

- 필요한 것: JDK 17, Android SDK(`build-tools;34.0.0`, `platforms;android-34`)
- 실행: `android/빌드.bat` (또는 `python android/build.py`) → `android/dist/교실호출.apk`
- minSdk 21 / targetSdk 29 — 오래된 전자칠판(Android 8~11)을 고려한 설정입니다.
- 윈도우에서 경로에 한글이 있으면 `aapt2` 가 실패합니다. 빌드 스크립트가 영문 폴더로 복사해 빌드합니다.

## 한계 (솔직하게)

- 칠판이 **완전히 꺼져 있으면** 방법이 없습니다. 소프트웨어로 전원을 켤 수는 없습니다.
- 칠판이 **HDMI(교실 PC 화면)** 를 비추는 중이면 안드로이드 화면이 가려져 안 보입니다. 이 경우 교실 PC 수신기가 대신 커버합니다.
- 채널 이름이 곧 접근 권한입니다. 암호화가 아니므로 민감한 내용은 보내지 마세요.
- 학교망 직접 전송은 교사 PC와 칠판이 같은 대역에 있을 때만 됩니다. 안 되면 중계로 자동 전환됩니다.
